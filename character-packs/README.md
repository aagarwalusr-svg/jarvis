# Download the Newman childhood personas

[Download the character pack](https://github.com/aagarwalusr-svg/jarvis/raw/refs/heads/feat/jarvis-command-center/character-packs/newman-personas.zip).

If your browser shows a file page, use **Download raw file**. On a phone, open the link in your browser and save to Files or Downloads, then extract the ZIP. Sign in to GitHub if repository access requires it.

The ZIP includes Julian and Jaden SVG expression drafts, PNG previews, JSON persona definitions, and AI/visual prompts. These are fictional childhood character studies, not real childhood photographs or documentary claims. No API keys, databases, or dependencies are included.

For the complete Claude Code project, open the repository branch, choose **Code → Download ZIP**, extract it, and follow `docs/CLAUDE_HANDOFF.md`.
